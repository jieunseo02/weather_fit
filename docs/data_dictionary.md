#  Weather-Fit Data Dictionary

패션 수요 예측 모델 (`weather_fit`) 프로젝트에서 사용되는 주요 데이터셋의 컬럼 정의 및 정제 규칙 문서입니다.

---

## w1. 지상 관측 일자료 (ASOS, W1)
* **설명:** 기상청 ASOS 관측소(서울 지점 `108`)에서 수집된 실제 관측 실황 데이터로, 패션 수요 예측 모델의 정답지 및 파생변수 생성의 기준선(Ground Truth) 역할을 합니다.
* **주요 주의사항:** 
  * 기온류(`TA_`, `TS_` 등)의 결측치는 `-99` 계열입니다. (영하권 실제 기온인 `-9.0` 등과 혼동 주의)
  * 일강수량(`RN_DAY`)의 `-9.0`은 결측이 아니라 **무강수(비 안 옴)**를 의미하므로 분석 전 `0.0`으로 치환해야 합니다.

### [패션 수요 예측 핵심 분석 컬럼 및 선정 근거]
패션 수요와 구매 심리에 직접적인 영향을 미치는 4대 축(기온, 일교차, 습도, 강수)을 반영하기 위해 W1 데이터에서 아래 6개의 핵심 컬럼을 선별하여 분석에 활용합니다.

| 컬럼명 (Column) | 한글명 | 선정 근거 (패션 수요 연관성) |
| :--- | :--- | :--- |
| **`TM`** | 관측일자 | 모든 시계열 분석의 기준선. 네이버 데이터랩 검색량(T1) 및 판매 데이터와 1:1 매칭을 위한 필수 축 |
| **`TA_AVG`** | 평균기온 | 전반적인 계절 변화 추세와 의류 교체 시기를 파악하는 기본 지표 |
| **`TA_MAX`** | 최고기온 | 낮 동안의 기온을 대변하며 반팔, 민소매, 린넨 등의 여름/환절기 의류 수요 결정 |
| **`TA_MIN`** | 최저기온 | 아침·저녁의 쌀쌀함을 대변하며 코트, 패딩, 내복 등의 방한 의류 수요 자극 (`최고기온 - 최저기온`으로 일교차 파생변수 생성의 재료) |
| **`HM_AVG`** | 평균 상대습도 | 체감온도에 지대한 영향을 미쳐 끈적함이나 건조함에 따른 소비자 구매 심리 보정 |
| **`RN_DAY`** | 일강수량 | 소비자의 외출 패턴을 바꾸는 외생 변수. 무강수(-9.0) 처리 후 `0.0`으로 변환하여 강수 여부(Is Rain) 판별 (`RN_DAY > 0`) |

#### ① 기본 시점 및 관측소 정보
| 컬럼명 (Column) | 한글명 | 설명 |
| :--- | :--- | :--- |
| **`TM`** | 관측일자 | 해당 관측 데이터의 날짜 (예: `2023-01-01`) |
| **`STN`** | 지점 번호 | 관측소 고유 번호 (서울은 `108`) |

#### ② 기온 관련 컬럼 (TA / TS / TG)
| 컬럼명 (Column) | 한글명 | 설명 |
| :--- | :--- | :--- |
| **`TA_AVG`** | 평균기온 | 하루 동안의 평균 기온 (℃) |
| **`TA_MAX`** | 최고기온 | 하루 중 가장 높았던 기온 (℃) |
| **`TA_MIN`** | 최저기온 | 하루 중 가장 낮았던 기온 (℃) |
| **`TA_MAX_TM`** | 최고기온 시각 | 최고기온이 발생한 시각 (HHMM) |
| **`TA_MIN_TM`** | 최저기온 시각 | 최저기온이 발생한 시각 (HHMM) |
| **`TD_AVG`** | 이슬점온도 | 공기가 포화상태에 이를 때의 온도 (℃) |
| **`TS_AVG`** | 지면온도 | 땅바닥 표면의 평균 온도 (℃) |
| **`TG_MIN`** | 초상최저기온 | 지표면이 차가워졌을 때의 최저온도 (℃) |

#### ③ 습도 및 증발산 관련 컬럼 (HM / PV / EV)
| 컬럼명 (Column) | 한글명 | 설명 |
| :--- | :--- | :--- |
| **`HM_AVG`** | 평균 상대습도 | 공기 중 수증기량을 백분율로 나타낸 값 (%) |
| **`HM_MIN`** | 최소습도 | 하루 중 가장 낮았던 상대습도 (%) |
| **`PV_AVG`** | 평균 수증기압 | 대기 중 수증기가 누르는 압력 (hPa) |
| **`EV_S` / `EV_L`** | 증발량 (소형/대형) | 물의 증발량 (mm) |

#### ④ 바람 및 풍속 관련 컬럼 (WD / WS)
| 컬럼명 (Column) | 한글명 | 설명 |
| :--- | :--- | :--- |
| **`WR_DAY`** | 주풍향 | 하루 동안 가장 자주 불어온 주된 풍향 |
| **`WS_AVG`** | 평균 풍속 | 하루 동안의 평균 바람 세기 (m/s) |
| **`WS_MAX`** | 최대 풍속 | 하루 중 순간적으로 가장 센 바람의 세기 (m/s) |
| **`WS_INS`** | 최대 순간풍속 | 돌풍 등 순간 최대 풍속 (m/s) |

#### ⑤ 기압 관련 컬럼 (PS)
| 컬럼명 (Column) | 한글명 | 설명 |
| :--- | :--- | :--- |
| **`PS_AVG`** | 평균 해면기압 | 해수면 높이로 보정한 평균 기압 (hPa) |
| **`PS_MAX` / `PS_MIN`** | 최고/최저 해면기압 | 하루 중 최고/최저 해면기압 (hPa) |

#### ⑥ 하늘상태 및 일조/일사 컬럼 (CA / SS / SI)
| 컬럼명 (Column) | 한글명 | 설명 |
| :--- | :--- | :--- |
| **`CA_TOT`** | 전운량 | 구름이 낀 정도 (0~10, 10이 완전 흐림) |
| **`SS_DAY`** | 합계 일조시간 | 태양 광선이 실제로 비친 시간 (hr) |
| **`SI_DAY`** | 합계 일사량 | 땅에 도달한 태양 에너지 총합 (MJ/m²) |

#### ⑦ 강수 및 적설 관련 컬럼 (RN / SD / TE)
| 컬럼명 (Column) | 한글명 | 설명 |
| :--- | :--- | :--- |
| **`RN_DAY`** | 일강수량 | 하루 동안 내린 비의 총량 (mm, `-9.0`은 무강수) |
| **`RN_D99`** | 강수 계속시간 | 비가 내린 총 시간 (hr) |
| **`RN_60M_MAX`** | 최대 60분 강수량 | 1시간 동안 가장 많이 내린 비의 양 (mm) |
| **`SD_NEW` / `SD_MAX`** | 신적설 / 최심적설 | 눈이 쌓인 높이 (cm) |
| **`TE_05` ~ `TE_50`** | 지중 온도 | 지하 깊이별 토양 온도 (℃) |
